# AI Travel Agent

An AI agent that finds real Airbnb listings using Google ADK.

## Features
- Real Airbnb search with prices and ratings
- Current date/time awareness
- Natural language interface

## Run it
```bash
export GOOGLE_API_KEY='your-key'
uv run adk web .
```
